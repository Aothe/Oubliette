the art bank

Every sprite the game has, drawn in code from one palette. One dungeon is built. The rest is banked, so a second dungeon starts with its tiles, its cast and its boss already drawn.

    Five dungeons

    Each plate is a mock room: that dungeon's tiles, a few of its props, its cast and its boss, with a delver for scale. Only the gaol is playable. The other four are art, and every name is a placeholder.

    The palette

    How the bank works

    It is data and a viewer. Nothing here is wired into a game.

    What a sprite is

    • A grid of letters in art/*.js. Each letter is a palette key.
    • Symmetric sprites are drawn as a left half and mirrored.
    • A recolour is a letter swap, so a gear tier or an elite enemy costs one line.

    What is settled, and what is not

    • The first release is one dungeon. Cards with a verdigris border are in it today.
    • Every name on this page is a placeholder. So are the classes: class design is still open.
    • No stats, no drop tables, no behaviour. This is what things look like, nothing more.

    Adding to it

    • Add a sprite with A.add(group, id, {…}) and reload this page.
    • node art/check.cjs catches a ragged row or a letter with no colour.
    • Painted art, such as key art or a logo, is outside what this method makes.
